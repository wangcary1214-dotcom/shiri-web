# 拾日网页版 1.8.0

网址：https://wangcary1214-dotcom.github.io/shiri-web/

静态 PWA，由 GitHub Pages 从 main 分支根目录发布，无构建步骤，无运行时第三方库。

## 每日手记

左栏“日记”支持按日期写标题、心情与图文正文。可多选、粘贴截图或拖入图片，正文支持加粗、斜体，图片可放大和移除。工具栏及 Ctrl/⌘ Z、Ctrl Y/⌘ Shift Z 可撤销和重做，编辑期间每个日期单独保留最多 80 步历史。

停笔约 0.9 秒自动保存，也可点“保存”或 Ctrl/⌘ S。保存失败会保留草稿并阻止切换；请重试或导出草稿。返回今天、前后翻日、日期选择与最近 30 篇回看均可使用。

单篇最多 30 张图片、10 万字；原图片最大 25 MB、5000 万像素，最长边缩至 1600 像素后存为 PNG。支持浏览器能解码的 PNG/JPEG/WebP/GIF/BMP；GIF 保存静态首帧。TIFF/HEIC 请先转为 PNG/JPEG。

“导出”支持包含所有图片的独立 HTML 和纯文本。日记页可导入旧版纯文字 diary.json。Windows 图文 diary.json 的图片在外部文件夹中，不能单独导入 JSON；可在 Windows 中导出图文 HTML 留存。

## 存储、恢复和完整备份

任务、计划和专注继续使用原 localStorage 存储键 shiri.web.v1。日记与图片在 IndexedDB 数据库 shiri-journal-v1 中，恢复草稿单独存于 localStorage。旧文字日记来源只读迁移，原值保留；跨页面写入冲突会提示并保留当前草稿。移除的图片不会立即删除，确保撤销和上次保存仍可恢复。

设置中的“导出全部备份”同时包含日程、专注、日记与图片。导入采用合并，同日期的已有日记保留本机版本。请定期备份；浏览器清理网站数据会删除本机记录。没有账号和自动同步。

缺少 IndexedDB 时可降级保存文字，图片入口会明确提示。持续保存权限由浏览器决定；不要把网页缓存当成唯一备份。

## 专注与陪伴

新专注整轮完成才计入统计，提前结束不计入，暂停可继续；历史已保存记录保留。统计日为北京时间 04:00 至次日 04:00。点击左栏“专注统计”查看今日饼图与最近一周柱状图。

大肥鱼的 71 张素材、台词表情映射和 75ms 点击动作保持原样，切换页面直接显示静态表情。

## 安装、更新和验证

首次保持联网直到“离线就绪”。iPad Safari 中选择“分享 → 添加到主屏幕”。已打开的旧页面请保存后刷新或重新打开，不要清除网站数据。

更新 sw.js 缓存版本，同时更新代码/样式引用的版本参数，避免旧 service worker 混用新旧模块。离线缓存只管理公开应用资源，不保存用户日记到网络缓存。

已在独立 Edge Chromium 档案验证实际存储、刷新、浏览器重开、备份恢复、撤销重做、异常草稿保护、离线和手机/平板视口；iPad Safari 真机尚未验收。
